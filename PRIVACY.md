# Privacy Policy

Last updated: 2026-09-26

This application ("Oura Excel") is a personal, non-commercial tool developed
and used solely by its author to export the author's own Oura Ring data to a
local spreadsheet for personal analysis.

## Data collection

The application does not onboard any users other than the author. No data is
collected from third parties.

## Data usage

Data retrieved from the Oura API is used only to populate the author's local
spreadsheet on the author's own device. Data is not shared with, sold to, or
transmitted to any third party.

## Data storage

Access tokens and exported data are stored locally on the author's device.
No data is stored on any server operated by the author.

## Third-party services

The application uses the Oura Cloud API (https://cloud.ouraring.com). The
Oura Ring service has its own privacy policy at
https://ouraring.com/privacy-policy.

## Contact

For questions about this privacy policy, contact the author via the email
address provided during Oura application registration.
